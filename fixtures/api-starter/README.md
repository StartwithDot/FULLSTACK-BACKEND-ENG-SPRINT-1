# Immutable Week 4 API shell

Copy this directory once to students/YOUR_ID/week-04/api. Run npm.cmd run dev:student -- YOUR_ID from the root.

This supplies only the app/listener split and liveness route. Add the event route and tests yourself in B01.1. Continue the same app through later weeks as described in docs/12-application-wiring.md.

Do not copy a later completed shared implementation into your own work. No nested npm install is needed; root dependencies support this shell.
