## Tool versions

Use the package.json and package-lock.json versions rather than installing latest independently. The starter selects TypeScript 5, Fastify 5, pg 8, React 19 and Vite 7. Node is the supported patched 22.x line; PostgreSQL is 17. Fastify 5.7 reference pages cover the APIs used here; if a later pinned patch differs, verify against that version's primary docs.

React's [from-scratch guidance](https://react.dev/learn/build-a-react-app-from-scratch) supports a small client-only app when learning basics. We use Vite for this bounded interface, not a full frontend framework course.

## AI-assisted learning

Use an assistant to explain an error or suggest a small experiment. Check the explanation against documentation and tests, keep secrets out of prompts and be able to rebuild/explain your result yourself. Do not submit an unexplained generated solution or fabricate test evidence.
