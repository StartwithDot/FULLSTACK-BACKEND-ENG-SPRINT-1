# Start Here

The cohort builds MerchantDesk, an application that records synthetic payment events and lets a merchant operator inspect them. Begin with the [client brief](01-project-brief.md).

## Your first session

1. Install Git, an editor and Node using sections 1-2 of [Windows setup](02-windows-setup.md).
2. Follow **Set up GitHub** in the [student guide](03-student-guide.md) to fork and clone the repository. Run `npm.cmd ci` inside that cloned folder.
3. Return to Windows setup for `setup:check`, `check` and the section 3 shell checks, then read the student guide's weekly workflow.
4. Find your BE number in [students/](../students/README.md).
5. Open `week-01/problem_statement.md` in your folder and follow its task link.

No prior programming experience, PostgreSQL, Docker, cloud account or payment-provider account is required for Week 1.

## The learning loop

Read the project requirement, investigate the relevant concept, attempt the task, test it and explain a decision. Review a peer's work. When assigned to the build rotation, promote the reviewed result into the shared application.

- **Sprint:** this complete 15-week course.
- **Week:** one learning, building and review block.
- **Track:** a recurring skill category, not a student specialisation.
- **Individual workspace:** your `students/BE##/` folder.
- **Shared build:** the single application in `shared/`.

Everyone completes the same 45 core tasks. Task IDs, paths, required proof and failure cases appear in the canonical week files. Follow the reading linked to the task you are doing, not entire documentation sites.

## Progress and support

Plan for about five hours weekly, including review and shared work. The [scope and pacing guide](11-scope-and-continuation.md) records the budget; task times are estimates. Milestone evidence determines readiness to advance.

When stuck, report the command, expected result, actual error and what you tried. Use [troubleshooting](09-troubleshooting.md) for common environment problems. Do not publish credentials or private student information.
