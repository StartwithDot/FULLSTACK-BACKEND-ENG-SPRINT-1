# One shared MerchantDesk build

The supplied API and UI shells run immediately. Merchant features are implemented by students using the [weekly build plan](../docs/08-shared-build-plan.md), not copied from a completed solution.

Students edit shared product paths through their assigned task branches and PRs, not directly on main. Each task has an available owner and a non-author reviewer; responsibilities rotate and unfinished work can be reassigned. Everyone completes the same individual practice. Witnesses reproduce behavior; a maintainer reviews security and database changes and merges passing PRs. See the [responsibility guide](../docs/06-team-roles.md).
