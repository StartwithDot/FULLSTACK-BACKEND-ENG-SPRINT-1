# One shared MerchantDesk build

The supplied API and UI shells run immediately. Merchant features are implemented by students using the [weekly build plan](../docs/08-shared-build-plan.md), not copied from a completed solution.

Only the current build pair edits shared product paths in its promotion PR. Everyone completes the same individual practice. Witnesses reproduce behavior; a mentor reviews security and database changes.
